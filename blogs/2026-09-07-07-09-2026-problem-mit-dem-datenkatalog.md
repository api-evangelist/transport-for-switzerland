Update 08.09.2026: Die Störung konnte behoben werden. Aktuell gibt es Probleme beim Herunterladen von Dateien aus unserem Datenkatalog (CKAN), das Problem wurde dem Lieferanten bereits gemeldet. Die API TrainFormationService (TFS) könnte bei einem allfälligen Neustart auch vom Problem betroffen sein, weil dann jeweils ein statischer Datensatz geladen wird.
